Baixar modelo de planilha

Importação completa (Turma + Aluno + Responsável)

Use esta opção para cadastrar tudo de uma vez a partir de uma planilha: a turma é criada automaticamente se ainda não existir (só o código — a grade de horários continua sendo importada à parte, na aba Turmas), o aluno é cadastrado e o responsável é criado e vinculado. Se dois alunos forem irmãos, repita os mesmos dados de responsável (mesmo CPF) nas duas linhas — o sistema identifica pelo CPF e não duplica o cadastro. As colunas de responsável podem ficar em branco se o aluno ainda não tiver um cadastrado.
